## Essential behavior to preserve

- No stock reservations for requests/planned events. Negative recorded balances are allowed.
- Relocations move actual quantities source → In Transit on shipment, then In Transit → destination on receipt.
- Events have Planning with no stock effects. Manager activation moves planned quantities directly to the event location. Additional deliveries recorded while active post immediately, including late entries during unfinished reconciliation. Unknown/external sources use positive adjustments.
- Multiple managers/sources contribute to one event. Reconcile one combined total per item. Distribution = brought minus remaining, including loss. Event remaining counts can be saved provisionally; blank is uncounted and zero is an actual count. All items must be counted to finalize.
- Leftovers default to the initial source, allow destination overrides/splits, and allocations must total remaining quantities.
- Finalize once with a prominent confirmation warning. Leftovers enter selected destinations immediately, with no In Transit. Finalized events never reopen. Any manager may make flagged corrections that update reports only; inventory corrections are separate manual location adjustments. Automatically generate dated plain-text correction logs. Explanations are optional.
- D-026's re-finalization/difference-posting model and D-019's reopening permission are superseded by D-028. Do not revive them.
- Event distribution reports are simple final item totals, printable and downloadable as CSV, without movement detail; corrections update the report.
- Location counts: personal saved searches retain all criteria including location/terms, never results. Include active items even at zero and inactive items with nonzero stock; exclude only inactive zero-stock items. Count individual items, not boxes.
- Print Inventory Worksheet → matching Reconcile Inventory form → Next with only changes and optional per-line Rationale → Save Updates creating separate corrections. Blank means no change. No print snapshots or intervening-movement warnings/conflict workflow. Counts are occasional, usually one manager per location.
- Starting inventory is a correction with note "starting inventory". Use further correction entries for mistakes.
- Item pages show Available (central + remote), individual locations including active events, shipped-request In Transit, and purchase Ordered. Active-event stock is excluded from Available. Do not double-count purchases in shipment In Transit.
- All actual stock changes feed an item ledger: date, signed quantity, location, who/what, rationale. Report-only event corrections do not create stock movements.
